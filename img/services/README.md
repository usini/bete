# Icônes de services intégrées

22 SVG embarqués, affichés depuis le même site que Bête. Aucun service distant de favicon,
CDN ou API de métadonnées n’est utilisé au moment de l’affichage.

Sources : [Simple Icons](https://github.com/simple-icons/simple-icons), version **16.36.0**,
sauf LinkedIn et Amazon (**13.0.0**) et Outlook (**11.0.0**). Les versions, sources et indications disponibles
pour chaque icône figurent dans [sources.json](sources.json).

Modifications : ajout d’une couleur de remplissage aux SVG monochromes ; X et GitHub sont
affichés en clair pour le fond sombre. Les tracés ne sont pas modifiés.
Amazon utilise le noir et l’orange, avec une zone de couleur sur le sourire.
